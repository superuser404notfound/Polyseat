Shared library

New seat

Mounts a directory from the host into this seat as a second Steam library. Games installed here become available in the other seats without being downloaded again, and vice versa. It does not share licences: a game still has to be owned by the account signed in to the seat. This is the only setting that mounts host storage into a seat.

Watch a library

Takes an existing Steam library into the pool and keeps watching it, which is how the games already on the host reach the seats and stay in step afterwards. Nothing is moved or deleted and nothing is ever written back: the files stay where they are and the pool shares their blocks.
